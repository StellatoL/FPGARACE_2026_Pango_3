# ARM轻量化ADAS验证记录（2026-10-22）

本轮范围是完成已批准方案的ARM实现、回归、可迁移构建和交付边界。用户确认最终模型仍在训练，权重先留空；工程没有生成占位权重，也没有将旧模型改名充当最终模型。

## 实现结果

- 正式输入仅为原有摄像头或HDMI经过FPGA/PCIe/DMA送入ARM。保留原MainWindow所有硬件按钮、调用和接口；没有增加ARM文件解码入口。
- 正式ADAS采用严格RGA输入适配、统一检测模型和独立车道模型的串行NPU调度。CPU处理模型张量、几何数值、跟踪、规则及Qt渲染，不执行基础像素处理。
- 感知分量分别维护代次、序号和新鲜度；四路按类别/视角隔离跟踪，转向后需目标侧新观测。前视放大不取消侧向安全检查。
- 单路保留虚线变道、实线保持、强制实线变道报警和导航跟随规则；全类别能力缺失、未知车道或目标路径障碍均拒绝授权。逻辑测试使用测试程序内的结构化观测，不提供生产注入入口。
- 灯色和导航各有独立ROI观测权限，完整场景检测不以空灯结果打断ROI确认。绿灯过期/失败后继续停等，连续无灯观测不能复用历史绿灯；需重新确认绿灯。
- 仿真速度默认0，外部速度缺失明确无效；取消正式ADAS的CPU视觉估速。保留来源绑定的四点标定、米制测距、TTC、近距报警和数值局部路径。
- 保留旧模式和旧权重文件；正式ADAS缺少新包时显示未配置并停车。

## 不计为通过的项目

1. **新模型推理和识别准确率**：最终权重尚未提供。输出契约、缺失/损坏/不兼容处理、有界解码和规则测试不等于实测感知精度。`project_video.mp4`只作为后续固定评测素材；本轮没有最终模型下的前后识别对比结论。
2. **PCIe与FPGA实流**：`lspci -nn`为空，无`/dev/pango*`。用户提供的`drivers/pango_pci_driver_mul.ko`为`6.1.99 SMP mod_unload aarch64`，与当前4.19.232内核不匹配，未强制加载、替换或修改驱动。需要匹配原上板系统后完成真实采集、源切换、DMA、原有处理按钮回归。
3. **性能与稳定性**：没有实测25fps预览、各路推理频率、P95延迟、功耗或30分钟连续实流。配置目标为四路前视8Hz/其余各2Hz、车道10Hz，单路检测/车道各12Hz，灯色/导航ROI各4Hz。按场景检测35ms、车道15ms估算四路占用920ms/s，仅是预算；最终模型可能需要重新优化调度。4Hz三次确认本身约500ms，必须纳入危险到报警总延迟。
4. **第二台实体RK3568**：用户无需远程第二台设备验证。本轮换目录构建检查路径和资源可迁移性；目标BSP的RGA/RKNN、内核和glibc兼容性仍需现场验证。
5. **FPGA处理的实际路径覆盖**：HDMI在参考RTL中走原始视频分支。不能将ARM模型后处理作为FPGA灰度、去噪、二值化、色彩转换验收；需在既有FPGA功能实际生效路径展示。
