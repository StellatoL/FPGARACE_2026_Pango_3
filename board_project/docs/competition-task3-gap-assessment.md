四宫格显示本身不是四路采集证明。按当前格式推算，1280×720×2×30的纯像素载荷约55.30MB/s（约52.73MiB/s），不含协议开销；这只是理论载荷，不能代替PCIe实际带宽测量，也不能证明四路摄像头各自更新。

预览FPS不是检测Hz；一次推理结果上屏耗时也不是危险触发到报警的总时间。文件计时从RGB565转换后开始，不含文件解码前段；所有内部延迟均不含曝光、FPGA前段、显示扫描和多帧确认。

现有交通任务约71ms，车辆任务约385–393ms。在当前串行调度下，目标14次/秒交通任务已约占994ms，再执行车辆任务就超过每秒预算。这是依据现有耗时的预算推算，不是实测NPU利用率。仅调整界面刷新或延长过期阈值，不能解决底层处理预算，也不能代替低延迟验收。
