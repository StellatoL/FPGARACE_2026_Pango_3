# 紫光同创 FPGA + RK3568 ADAS

2026-10-29：启动入口已兼容 `sh run_adas.sh`，ADAS 状态与告警集中显示在视频内；输入FPS按FPGA收帧统计，右侧不再堆叠ADAS状态。灯色有效空检测立即撤销旧色与隐式灯控，失败/过期显示无信号并保留必要停车约束；碰撞近区改为短区域并按底部接地足迹判断。详见[本轮操作与单路验证](docs/operator-hdmi-verification-2026-10-29.md)。

当前程序只保留 **ADAS 与纯视频** 两种模式。ARM 端车牌识别、旧交通场景程序及其权重、旧八类/960兼容路径、神经网络车道、视觉导航与视觉估速、文件播放源均已删除。传统车道、短时目标跟踪、手动导航及四路侧向安全判断保留。

## 输入与 FPGA 边界

```text
电脑播放U盘图片/视频 → HDMI → FPGA → 原PCIe/DMA → ARM显示
四路摄像头 → FPGA拼接 → 原PCIe/DMA → ARM显示
```

传输为1280×720 RGB565。HDMI按整幅前视处理；摄像头四路依次为左上前、右上右、左下后、右下左，各640×360。界面前视放大只改变显示，不取消四路安全判断。ARM没有生产文件播放入口；电脑换素材、暂停或跳转后需手动复位决策，现有接口不提供媒体事件或PTS。

`src/hardware`、驱动、FPGA设计和上板bitstream保持原字节。原有摄像头/HDMI切源、预处理、白平衡、去雾、FPGA车牌定位框等按钮保留；**FPGA车牌框按钮与已删除的ARM车牌文字识别是两个功能**。不新增FPGA寄存器、协议或驱动操作。RTL显示HDMI走原始视频分支，不能把ARM识别结果记成FPGA预处理验收。

## 编译与运行

在64位AArch64 RK3568 Linux使用C++17、Qt5/qmake、OpenCV4、工程内RKNN运行库及系统RGA：

```bash
./build.sh --check
./build.sh --install-deps       # Ubuntu/Debian缺依赖时显式使用
./build.sh
./run_adas.sh                  # 也支持 sh ./run_adas.sh
```

默认输出`build_adas`、编译并发2；支持`BUILD_DIR=/path/to/output BUILD_JOBS=2 ./build.sh`，再运行该目录的`run_img_recv_demo.sh`。资源按位置定位，不依赖开发机绝对路径。迁移和外置输出详见[RK3568迁移说明](docs/rk3568-migration.md)。`--clean`仅清理脚本拥有的构建目录；`--no-rga`供诊断，目标检测会明确报告不可用，不回退CPU适配。

仓库入口为`board_project/`，克隆后进入该目录构建。驱动明确纳入版本控制：`drivers/pango_pci_driver_mul.ko`，校验见`drivers/SHA256SUMS`。同为RK3568也须匹配内核、RGA及NPU BSP；构建脚本不会自动加载驱动。

## 感知与调度

唯一模型包为`models/adas/{manifest.json,vehicle.rknn,traffic.rknn}`，schema3、RK3568 INT8、640×640 RGB8/NHWC、mean0/std255、黑色letterbox。加载时校验SHA、类序、输出形状、激活契约和SDK。

| 模块 | 作用 |
|---|---|
| vehicle / NPU | 官方Rockchip YOLOv5n COCO80，仅取person、bicycle、car、motorcycle、bus、truck，作为主人员/车辆观测 |
| traffic / NPU | 原6类crosswalk、person、light_red、light_green、light_black、light_yellow；person仅辅助过街风险，侧后视无灯控权限 |
| 传统车道 / CPU独立线程 | 白黄掩码、边缘、Hough聚类、拟合和原图漆段复核；输出本车道左右边界与实/虚/未知 |
| 目标跟踪 | 按来源代次、视角、类别隔离，有限常速预测与IoU关联，补偿短时漏检 |

单NPU线程常驻两个上下文，实际开始任务全局严格Vehicle/Traffic交替。每个角色前视上限8Hz，另三视角各2Hz；有转向意图时目标侧4Hz、其余侧后视各1Hz。HDMI单路仅处理整幅前视。CPU车道目标15Hz。以上是调度预算，实际频率受串行推理耗时限制。

前视有效期500ms、侧后视1.5s。预测框以橙色虚线显示，前视最多0.35s、侧后视0.75s；预测不增加确认票、不生成测距/TTC、不清除危险。空检测、模型缺失、失败与过期分别处理。当前没有锥桶/路栏/掉落物检测，不能宣称这些能力。

两模型精确输入输出、锚框、来源和替换要求见[模型接入说明](docs/model-replacement-roadmap.md)。旧schema1/2、八类、960和车道网络包不再被接受。

## 操作与演示

| 按键 | 模拟操作 |
|---|---|
| `1 / 2 / 3` | 选择左/直行/右车道 |
| `↑ / ↓` | 普通行驶 / 人工停车 |
| `Ctrl+↑` | 强制行驶请求，红灯时报警 |
| `← / →` | 手动导航左/右，同时给出转向意图 |
| `W / N / Esc` | 直行导航 / 循环导航方向 / 清除导航及强制状态 |
| `Ctrl+← / Ctrl+→` | 强制左/右变道请求，实线时报警 |
| `A / D`、`J / L`、空格、`V` | 转向灯、强制变道、停车切换、切换显示 |

编辑输入框时禁用驾驶快捷键，键盘自动重复不刷新安全请求。所有强制动作均由操作者触发；导航无需视觉识别。模拟速度与限速可手动设置，默认0和60km/h；没有视觉或外部速度输入模式。

- 路口：红/黄灯停车，确认绿灯后放行；绿灯不解除人工或紧急停车。已确认红灯下手动强制行驶触发屏内红色报警。最新有效全空灯色观测立即清除旧红/绿、闯灯报警及隐式路口状态；失败/过期不会沿用旧色，显式路口或其他车道仍有灯时保持未知停车。黑灯不能借用旧绿通行。
- 路段：虚线且路径安全时变道；实线直行，强制实线变道报警；未知不授权。四路还要求目标侧人员/车辆观测有效、新鲜、晚于请求且无相关阻挡；单路只判断前视可见路径，不伪造侧向安全结论。
- 导航：操作者根据电脑视频中的导航输入方向，路段变道遵守同一安全约束。
- 行人/近距风险：显示紧急刹车与警告；只能由对应来源新的有效真实观测确认解除危险。

红灯强行驶、实线强制变道、行人急刹、碰撞、超速和压实线都会在视频顶部显示文字与红色横幅。顶部显示驾驶行为、方向、手动导航与灯色；底部显示FPGA输入FPS，含帧池压力下未进入处理的输入帧，不是渲染FPS，也不是电脑原文件的帧率元数据。

静态图片经HDMI输入同样可以手动操作。切换图片/视频后点击复位决策；改变来源或路面后重做标定。四点标定绑定来源和尺寸；车头偏移未测时不显示米数，未标定仍保留图像近距和框尺度TTC。

## 验证与目录

```bash
./tests/run_tests.sh            # 先完成应用构建，含Qt回归
./tests/build_script_test.sh
ADAS_TEST_RGA=1 ./tests/run_tests.sh   # 需要真实RGA，可选
```

`tests/`保留当前规则、调度、线程、契约和界面回归；`tools/`仅保留离线诊断和实流性能统计。离线诊断接收工程外图片/视频，只用于测试，不进入生产采集链路：

```bash
tools/run_scene_diagnostics.sh -- --input /path/to/test.mp4 --output /tmp/adas-check --max-frames 20
```
