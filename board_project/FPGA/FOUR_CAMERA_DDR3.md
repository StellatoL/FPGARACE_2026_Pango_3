# 四路摄像头 DDR3 拼接与 HDMI 直通

## 视频通路

摄像头：四路独立 OV5640 采集 → 每路 1280×720 RGB565 抽取为 640×360 → 四个独立 DDR3 帧区 → 按行读出并组成 1280×720 四宫格 → 可选原有预处理 → PCIe。

HDMI：1080p60 → 原有滤波降采样为 1280×720 → 保留隔帧以得到 30 fps → PCIe。HDMI 像素不经过 VIP/VPD 或 DDR3。缩放模块名字含 `ddr`，实际使用 FPGA 内部行存储，没有外部 DDR3 接口。

## 摄像头接口

| 象限 | 顶层接口 | 参数位 |
|---|---|---|
| 左上 | 原有 `cmos_*` | `CAMERA_ENABLE[0]` |
| 右上 | `cmos2_*` | `CAMERA_ENABLE[1]` |
| 左下 | `cmos3_*` | `CAMERA_ENABLE[2]` |
| 右下 | `cmos4_*` | `CAMERA_ENABLE[3]` |

当前 RTL 默认 `CAMERA_ENABLE=4'b1111`，四路采集、四路 DDR3 缓存和四宫格输出同时工作。现有摄像头连接器仍映射到 `cmos3_*`，所以它对应左下象限；其余三个接口保留为独立端口，等待按原理图填写引脚。不要通过复制 `cmos3_*` 的 LOC 来绑定其他摄像头，否则会产生管脚冲突。

约束映射文件为 `prj/pcie_video.fdc` 和 `prj/device_map/hdmi_out_top.pcf`。当前 `cmos3_*` 的 LOC 是已有连接器的有效绑定；`cmos_*`、`cmos2_*`、`cmos4_*` 的 LOC 要在 `pcie_video.fdc` 中按板卡原理图逐一填写，包括 `scl/sda/reset/pclk/vsync/href/data[7:0]`。

绑定完成后保持 `CAMERA_ENABLE=4'b1111` 重新执行综合、布局布线和生成 bitstream。未接入的摄像头即使保持使能，也只会输出对应黑色象限；接入并正确配置 SCCB 后才会出现图像。

当前驱动按 OV5640 的 1280×720 RGB565 模式配置。换其他型号需要适配传感器配置和采集接口；DDR3 拼接模块的输入是独立像素时钟、正极性 VS、连续 640 像素行 DE 和 RGB565 数据。

`camera_quad_reshape.v` 保留每隔一个像素和每隔一行的采样点，随后利用内部行存储输出连续的 640 像素行。这保留了参考工程的四宫格缩小布局，并适配 `pcie_image` 原有帧缓存的连续行要求，不是截取原图左上角。

## DDR3 帧区与读写

DDR3 接口地址单位沿用原工程的 16 位 DDR 数据字，每个 128 位数据拍跨 8 个地址单位。

每路包含四个帧槽，单槽跨度 `0x40000` 地址单位，实际图像占用 `640×360=230400` 个地址单位。通道基址如下：

| 通道 | 基址 | 四个帧槽地址范围 |
|---|---|---|
| 0 | `0x000000` | `0x000000`–`0x0FFFFF` |
| 1 | `0x100000` | `0x100000`–`0x1FFFFF` |
| 2 | `0x200000` | `0x200000`–`0x2FFFFF` |
| 3 | `0x300000` | `0x300000`–`0x3FFFFF` |

只有完成 360 行 DDR 写命令后，该帧槽才会发布给读端。读端在拼接帧的 VS 边界选择最新完成帧并锁定帧槽；写端轮转时同时跳过被读端锁定的槽和最新完成槽，避免在读帧切换前覆盖待选帧。四个摄像头可使用不同像素时钟；同一拼接帧使用每路最新完成帧，不提供四个传感器的曝光同步。

`quad_ddr3_framebuffer.v` 对四个帧缓存的 AXI 读写分别做轮询仲裁，一次锁定一个突发的所属通道，读响应和写突发结束标志仅送回对应通道。输出每行先读左侧通道 640 像素，再读右侧通道 640 像素；前 360 行使用通道 0/1，后 360 行使用通道 2/3。禁用或尚未完成首帧的通道输出黑色，仍保留完整 1280×720 栅格。

摄像头读出时钟为现有 `clk_50m`，保留 1650×750 总时序，输出约 40.4 fps，可重复读取完成帧。HDMI 的 30 fps 来自 60 fps 输入隔帧，与摄像头读出时钟无关。

## 切换与 PCIe

I2C `0x01[0]` 和原有按键保持视频源选择功能：0 为摄像头四宫格，1 为 HDMI。摄像头模式可使用原有预处理控制寄存器；HDMI 模式强制绕过处理。

切换源时暂停视频输入并清理发送 FIFO，随后等待新源帧起点。切回摄像头后，各写端在自身下一帧 VS 开始接收数据。切入 HDMI 后停止摄像头的新写数据及拼接读时序，已发出的 DDR 突发允许完成。

PCIe 保留 RGB565、每行 2560 字节 DMA、720 行及主机四帧地址轮转协议。DMA 依据 PCIe 域 FIFO 中是否具备完整的 160 个 128 位字发起，等待上一行 DMA 完成后再发送下一行。

## 验证状态

针对 DRM 超限，禁用通道现在由 `generate` 排除帧缓存实例。启用的 640×360 通道每个读/写行缓存从 131072 bit 缩至 65536 bit（2048×32 / 512×128），各可容纳 6.4 行 RGB565 数据；完整帧及四个帧槽仍存放在外部 DDR3。RAM IP 包装模块增加了地址宽度参数，非四宫格模式保持原有深度。重新生成 `wr_fram_buf` / `rd_fram_buf` IP 时需保留这些参数扩展。

本次修改未运行仿真、PDS 综合、布局布线或板上验证，原有 bitstream 不是本次修改的构建结果。新增摄像头的物理引脚与时钟约束仍按任务要求留待接线时填写。
