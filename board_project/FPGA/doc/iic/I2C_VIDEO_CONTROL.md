# ARM/RK I²C 视频控制

FPGA 的 7 位 I²C 从地址为 `0x66`。

| 寄存器 | 位 | 访问 | 含义 |
| --- | --- | --- | --- |
| `0x00` | `[7:0]` | 读写 | 通信测试回环寄存器 |
| `0x01` | `[0]` | 读写 | 视频源：`0` 摄像头，`1` HDMI |
| `0x02` | `[0]` | 只读 | 当前实际视频源：`0` 摄像头，`1` HDMI |
| `0x03` | `[0]` | 读写 | 预处理总开关：`0` 关闭，`1` 开启 |
| `0x04` | `[0]` | 读写 | 车牌定位/画框总开关：`0` 关闭，`1` 开启 |
| `0x05` | `[0]` | 读写 | 白平衡特性：`0` 关闭，`1` 开启（仅在 `0x03=1` 时生效） |
| `0x06` | `[0]` | 读写 | 暗通道去雾特性：`0` 关闭，`1` 开启（仅在 `0x03=1` 时生效） |

以下命令以 Linux I²C 总线 0 为例：

```sh
# 开启/关闭预处理
i2cset -f -y -a 0 0x66 0x03 0x01
i2cset -f -y -a 0 0x66 0x03 0x00

# 开启/关闭车牌定位和画框
i2cset -f -y -a 0 0x66 0x04 0x01
i2cset -f -y -a 0 0x66 0x04 0x00

# 开启/关闭白平衡
i2cset -f -y -a 0 0x66 0x05 0x01
i2cset -f -y -a 0 0x66 0x05 0x00

# 开启/关闭暗通道去雾
i2cset -f -y -a 0 0x66 0x06 0x01
i2cset -f -y -a 0 0x66 0x06 0x00
```

处理链切换会在视频帧边界执行。由于直通路径与处理路径存在不同延迟，
切换期间输出会短暂消隐，以避免把两个路径的一部分拼到同一帧。
两个总开关以及白平衡、去雾控制位跨入当前像素时钟域后，在输入帧边界更新。
四个控制寄存器上电默认均为 `0`。白平衡和去雾寄存器可以预先配置，
但只有预处理总开关 `0x03=1` 时才参与图像处理。预处理和画框彼此独立，
因此支持原图、仅预处理、仅画框、预处理加画框四种组合。
关闭后，VIP 总模块及其白平衡、亮度增强、暗通道去雾、双边滤波模块
都进入零延迟直通状态：同步信号和像素输出等于当前输入。VDP 与画框
模块随后保持复位，PCIe 输出路径直接使用 `video_channel_selector` 的
原始结果。
