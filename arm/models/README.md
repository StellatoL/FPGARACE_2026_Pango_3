# 导入模型

模型二进制保留本地，不随 Git 提交。完整应用需要补齐前三个必需模型；本次原始模型未修改、未重新转换，完整 SHA256 和大小见 [assets.json](assets.json)。该清单也记录运行库、预编译驱动和归档程序，所有路径相对整体工程根目录。

| 文件 | 当前代码用途 |
|---|---|
| `plate_yolov5.rknn` | 车牌区域检测 |
| `plate_lprnet.rknn` | 车牌字符推理；具体输入/输出与字符集需按模型实测核对 |
| `traffic_yolov5.rknn` | 6 类交通主检测模型，ADAS 流程依赖其就绪 |
| `yolov5s_traffic.rknn` | 可选车辆检测辅助模型 |

构建会将四个模型复制到可执行文件旁的 `models/`。源文件保留在此目录；生成副本由版本控制忽略。

仅凭模型文件名不能确定训练来源、许可证、RKNN Toolkit 版本和内部布局。本次未重新验证 NPU 数值输出或识别率。两个转换工具需要外部源码/权重，默认输出 `arm/build/model-conversion/`，不要直接替换这里的已导入资产；先核对维度、归一化、字符表与后处理兼容性。
