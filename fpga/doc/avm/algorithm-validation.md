# 四路 AVM 算法与定点参考验证

本文件记录已实际运行的算法验证；ModelSim 吞吐、资源映射和上板状态由系统验证报告单独记录。源代码、输入数据和结果均可用 `tools/avm/README.md` 中的命令重建。

## 联合映射与场景

合成场景采用世界坐标 X 向右、Y 向前、Z 向上，地面 Z=0；相机坐标 X 向右、Y 向下、Z 向前。输出宽度对应 16 m，高度按像素比例计算，车身遮罩为 X∈(-0.8,0.8)、Y∈(-1.4,1.4) m。前后相机中心为 (0,±1.2,1.2) m，左右为 (±0.65,0,1.2) m；朝外下视。内参及四个非零畸变系数保存在各样例 `calibration.json` 中。

原始合成图像由每个传感器像素的鱼眼反投影射线与地面求交后生成；它不读取输出 LUT。独立检查另以 OpenCV `fisheye.projectPoints` 投影已知地面点，再用解析射线反解：720p 样例的 50 个有效控制点最大地面误差为 2.62×10⁻¹⁴ m。前红、后蓝、左黄、右绿标记及米制网格用于检查方向与尺度。合成 720p 的非车身地面覆盖率为 100%。

公开场景使用 `neozhaoliang/surround-view-system-introduction` 的提交 `0c40d7e12443a7f16b2adae6f79fae2f6d6ee071`。四路源图为 960×640；原 1200×1600 鸟瞰缩放至 540×720，居中放在 1280×720 画布，左右各补 370 像素。适配器组合原项目的翻转、逆投影矩阵和调整后内参，再进入原始 fisheye 模型。没有生成中间去畸变图，也没有虚构公开样例的物理外参。下载文件均校验固定 SHA256；版权和完整 MIT 许可见 `tools/avm/THIRD_PARTY_LICENSE.txt`。

鱼眼模型使用 OpenCV 四系数形式 `θd=θ(1+k1θ²+k2θ⁴+k3θ⁶+k4θ⁸)`，与 MATLAB 自带 fisheye 参数模型区分。MATLAB `verify_mapping.m` 独立计算同一数学模型和完整双精度像素参考，未调用 Python 重映射实现。

## 网格、插值与路由

每个 16×16 宏块、每路相机分别从 16/8/4/2/1 像素步长选择最粗合格网格。节点先量化为有符号 21 位 Q8，水平插值先按最近值、半值远离零舍入，再对垂直插值执行相同规则；误差门限在这两个实际舍入之后测量。所有几何有效像素的源坐标欧氏误差须 ≤0.25 像素。边缘宏块按 16×16 填充，但越过输出边界的路由无效。负坐标、图像右下边缘不能取得完整 2×2 像素组的位置不参与采样。

路由最多选择相邻的两路相机，只允许前左、前右、后左、后右组合。`small`、`public` 和 `synthetic720-wide` 交叠中按相机有效域的距离变换生成渐变权重。`synthetic720` 默认采用有物理标定的相机所有权和 64 像素有限接缝带，详见下文。不具备有效相邻对时退回覆盖有效的单路；全无效则填黑。实际采样先将 RGB565 按位复制展开至 RGB888，单次双线性插值后再执行 Q4.12 增益与互补 Alpha 混合，最终截断回 RGB565。

| 样例 | 输出 | 最大坐标误差/px | 节点字节数 | PSNR/dB | SSIM |
|---|---:|---:|---:|---:|---:|
| small | 64×48 | 0.241739 | 51,552 | 39.881 | 0.979693 |
| synthetic720，64px 接缝 | 1280×720 | 0.249970 | 300,976 | 39.369 | 0.993499 |
| synthetic720-wide，全交叠压力 | 1280×720 | 0.249970 | 300,976 | 39.821 | 0.991279 |
| public | 1280×720 | 0.249855 | 216,896 | 35.257 | 0.974747 |

PSNR/SSIM 在可见区域中，将输出 RGB565 展开的 RGB 与联合映射双精度参考比较；包含最终 RGB565 量化损失。SSIM 使用 11×11、σ=1.5 的高斯窗口。公开样例的精确网格节点约 211.8 KiB，超过规划阶段约 145 KiB 的初步估计；实际误差门限、节点打包及有效域取值以本实现结果为准。720p 的额外描述符为 230,400 字节，逐像素路由为 1,843,200 字节，均驻留 DDR。



## 有限接缝与全交叠压力配置

鱼眼相机的几何可见范围很宽，但实际 AVM 只需在相邻视图的接缝带中重叠混合。原全交叠样例有 832,724 个双路采样像素；它保留为 `synthetic720-wide`，继续接受位精确和性能验证。默认 `synthetic720` 使用 64 像素接缝带；两种配置均受支持，不能将有限接缝的 30fps 测量外推为全交叠压力配置的性能。

有限接缝先从 K/D/R/t 对应的世界坐标求每路相机水平光轴方向与中心。对每个有效地面点，沿水平光轴的有符号距离最大者拥有该点。随后对四个有效所有权区域分别求外部距离，选择最近的有效相邻区域，使用 `α=clip(0.5+max(0,d−0.5)/64,0.5,1)`。半像素偏移将离散相邻区域像素中心的距离对应到边界。α=1 时关闭第二路采样；车身和无效画布不归属任何相机，避免它们产生虚假的距离平台。公开数据只有投影适配矩阵，保留其现有权重策略。

这次改动只改变路由和权重，未改变相机采样密度、鱼眼系数、raw 图像、DDR 行为模型或 0.25 像素精度门限。独立回归对比 wide/finite 的标定文件、DDR 描述符/节点/raw 字节，以及全部浮点映射、定点坐标、有效域和误差数组，均完全相同；非车身地面覆盖仍为 100%。

| 配置 | 双路像素 | 总有效取样请求 | 相对全交叠 |
|---|---:|---:|---:|
| synthetic720-wide | 832,724 | 1,725,652 | 基准 |
| synthetic720，64px | 93,932 | 986,860 | 请求减少 42.81% |

已检查所有 **1,783,504 条**水平/垂直可见相邻像素边：相机进入/退出的权重变化不超过 4/256，四相机权重向量的 L1 变化不超过 8/256，超过阈值的来源切换为 0。MATLAB 按新路由重新渲染完整 720p 图，仍逐 RGB 分量零差异。有限接缝的 PSNR 比宽融合低约 0.45 dB，是宽区域平均两路量化误差的效果减少；SSIM 从 0.991279 上升到 0.993499，几何映射误差不变。两者使用各自同策略的双精度参考，不能把不同接缝策略间的像素差解释成 RTL 错误。


## 独立验证与曝光反馈

四个样例均实际调用 MATLAB R2024b：small 检查 64 个坐标点，synthetic720、synthetic720-wide、public 各检查 17,024 个坐标点；最大坐标差依次为 1.59×10⁻¹⁴、2.54×10⁻¹³、2.54×10⁻¹³、2.03×10⁻¹² 像素。MATLAB 又独立渲染 small 的全部 3,072 像素及其余三个样例各 921,600 像素，四组与 Python 双精度参考均逐 RGB 分量完全一致。

Python 共 13 项自动测试，包括有符号半值舍入、全部 65,536 种 RGB565 往返、随机带符号网格的独立标量插值、像素双线性随机标量算式、颜色饱和与权重端点、仅相邻对路由、相机几何，以及从 DDR 字节重新解码 small 全帧的独立标量参考。后者直接读描述符、节点、路由和原始帧，未复用生成器的网格与像素运算函数，因此能发现打包、字节序与寻址错误。新增两项验收检查有限接缝的逐像素来源/权重连续性，以及它相对于原 wide 的几何与源数据完全不变。

曝光统计取补偿前插值 RGB；仅当两路相机六个颜色分量都处于闭区间 [16,235] 时，累加一组 RGB 和公共计数。每通道求有界对数域最小二乘，约束增益 0.5～2.0、四路对数增益和为零。通过枚举四变量的活动边界求解，避免先裁剪再归一导致约束失效。有效图不连通时保持该颜色通道原增益；5 Hz 更新采用 0.1 对数域 EMA。

最终回归将 **实际 ModelSim synthetic720（64px 有限接缝）输出的四对统计** 输入 `exposure.py`，重复 60 次静态帧反馈，并按实际 Q4.12 寄存器值计算补偿后残差：

- 交叠均值相对残差从 **9.36023%** 降至 **0.23807%**。
- 最差相机对/颜色通道残差为 **0.37392%**，满足可达、非饱和、连通曝光样例的 ≤2% 目标。
- Q4.12 增益为前 `[4516,4148,3962]`、后 `[3730,4442,4289]`、左 `[3979,3844,4459]`、右 `[4200,3974,3715]`。
- 明细及 60 次状态记录保存为 `exposure-feedback.json`；供寄存器写入的值保存为 `gains.json`。`apply_gains.py` 已为 small 与 synthetic720 生成第二帧配置/参考，保持 DDR 镜像和第一帧数据不变。


这是采样统计驱动的静态反馈回放，不宣称已有实时 ARM 驱动。公开实拍场景经过同样统计过滤后，平均残差从约 12.81% 降至 7.79%；地面标定误差、不同视点、立体对象及局部光照不能由每路一个全局增益完全消除，因此不将公开样例描述为无缝融合。地面平面模型的高物体拉伸和运动重影仍是边界。

公开版本省略实拍原图及历史图表附件；当前摘要见 [验证结果](../validation/README.md)，重新生成图表可执行 tools/avm/render_report.py。
