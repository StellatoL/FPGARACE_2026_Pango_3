# FPGA 工程 README 与 GitHub 提交计划

**Goal:** 为整理后的四路 AVM FPGA 工程编写可从全新克隆开始使用的详细 README，检查实际待提交内容中的敏感信息，并提交到用户指定的 `StellatoL/FPGARACE_2026_Pango_3`。

**Architecture:** 保留本地完整工程和原始验证证据；在 `build/publish/` 内建立发布工作副本，按明确清单导出源码、工具、文档和经过审查的验证摘要。原始日志、二进制、备份和本机目录不进入 Git。发布源码与已验证源码逐文件 SHA256 对照，报告明确区分原始证据与公开摘要。

**Tech Stack:** Git、Python、PowerShell、ModelSim；不改变生产 RTL、算法或 PDS 约束。

用户已授权提交与推送。先完成此计划、独立审阅和具体提交内容，再执行发布；无需重复要求用户确认常规提交操作。当前网络读取遇到审批服务故障，可先完成全部本地工作；如果发布仍被阻止，保留本地提交并如实报告，不能声称推送成功。
