# 系统验证摘要

本摘要对应 2026-10-03 实际工具运行和源码核验。原始本机日志保留本地，提交中的摘要与 PASS 摘录不冒充未经处理的原始日志。

| 项目 | 已验证结果 |
|---|---|
| FPGA Python | 13 项通过、0 跳过 |
| ModelSim RTL 单元 | 9 次运行通过；重排运行内含多个尺寸 |
| ModelSim 整帧 | 8 组、10 帧、5,541,888 个像素逐一一致 |
| PDS ADS | PG2L50H-6IFBG484、1280×720、100 MHz 目标，综合成功 |
| 综合网表功能仿真 | 921,600 个像素逐一一致，官方原语、零延迟、无 SDF |
| ARM CPU | 41 条 ADAS、15 条车道/导航、5 项字符比较、7 条合成视频 E2E 通过 |
| ARM 入口 | Bash、qmake 解析、模型部署、启动参数与架构保护通过 |
| MATLAB | 此前四组独立参考已通过；本轮复用结果，没有重新运行 |

证据文件：[结果 JSON](results.json)、[源码 SHA256](source-sha256.json)、[实际 PASS 摘录](pass-markers.txt)。结果 JSON 保存本地原始摘要的 SHA256 来源标识。源码摘要中包含测试/工具文件，文档变动不等于重新执行硬件验证。

综合资源为 9,732 LUT、8,871 FF、52 DRM36K、66 APM；估计 Fmax 103.8529 MHz，100 MHz 下 slack +0.371 ns。该估计不是布局布线时序签核。

720p 有限接缝标称处理 28.31660 ms；全交叠 36.34548 ms、随机压力 54.58745 ms，后两者未达到 30 fps。数值来自 DDR 事务模型中的帧就绪到最后像素，不是板端端到端帧率。

ARM 结果来自 WSL x86_64 / Qt 5.15.13 / OpenCV 4.6.0。视频输入使用原场景函数、OpenCV mp4v 编码；E2E 不经过 RKNN、PCIe、Qt 队列或 GUI。导入历史记录写 ADAS 42 项，当前实际输出 41 条断言，摘要采用实测数值。

**尚未验证：** 当前 FPGA—ARM 板级连接、真实四路相机、物理 DDR/PCIe、AArch64 完整应用、NPU、实体 LED、CDC、布局布线及板级时序。没有可直接烧录的完整系统 bitstream。导入的 ARM 板端文件回放记录不是整机联调证据。

从全新克隆复现时，先看 [整体 README](../../README.md)、[FPGA 指南](../../fpga/README.md)、[ARM 指南](../../arm/README.md)。仓库不提供受限 SDK 头文件或模型/runtime 二进制；CPU 测试可独立运行。

发布副本重新生成 small 输入并通过 3,072 像素压力仿真、全部 9 次 RTL 单元及 ARM 41/15/5/7 项 CPU/视频检查；qmake 解析通过，缺少外部 SDK 时构建检查按预期明确报错。上述发布副本检查没有重跑完整 PDS/720p 回归，完整结果仍绑定此前实测的相同生产源码。

按用户要求，仓库包含预编译 PCIe 驱动。检查发现 4 处个人目录，仅在非加载 DWARF 调试区中作等长替换；全部其他字节不变，见 [处理记录](../../arm/drivers/prebuilt/publication-metadata.json)。此检查验证文件完整性和脱敏范围，不代表完成板端加载或 AVM 联调。
